Local vs. Global Variables

Global variable: The myPerson object is declared inside the script tag, outside the functions. This lets multiple functions access and change the same object.

Local variable: The output variable is declared inside showObject(). It can only be used inside that function.

Declaring an object outside the functions is useful when multiple functions need to access the same data. However, keeping variables local when possible helps prevent accidental changes.
